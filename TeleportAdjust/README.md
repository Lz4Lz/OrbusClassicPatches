# Teleport Adjustment

Lets you adjust the teleportation beam. Adjustment is done in the config file: `orbusvrcommunity.teleportadjustment.cfg`

```
## Settings file was created by plugin Orbus Classic/Preborn Teleporter Adjustment v1.0.0
## Plugin GUID: orbusvrcommunity.teleportadjustment

[Teleport]

## Tilts the teleporters aim axis up/down (positive = down)
# Setting type: Single
# Default value: 0
X = 0

## Turns the teleporters aim axis left/right (positive = right)
# Setting type: Single
# Default value: 0
Y = 0
```
