## WeaponAdjustment

Recommended to use WeaponAdjustment instead. It works like on Reborn and doesn't require you to type in the config values, instead there is an in-game menu entry and editor.

## Wand Adjustment

You can configure the adjustment in: `OrbusVR/BepInEx/config/orbusvrcommunity.wandadjustment.cfg`

It will generate once you launch the game with this patch installed. If not, you can place it directly in: `OrbusVR/BepInEx/config`.
